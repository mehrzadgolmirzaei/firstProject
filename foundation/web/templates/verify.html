فایل‌ها

خود مدل: گره‌ها، اعضا، مقاطع و بارها. در SAP: File ← Export ← SAP2000 .s2k Text File.
مدل دیگر نیست؛ جدول نتایجی است که SAP بعد از تحلیل و طراحی می‌دهد (عکس‌العمل تکیه‌گاه‌ها و نسبت تنش اعضا). روش گرفتنش در پایین آمده است.

گرفتن فایل ۲ از SAP
  1. مدل را در SAP باز کنید؛ واحد پایین صفحه Kgf, m, C باشد.
  2. Analyze ← Run Analysis (کلید F5).
  3. Design ← Steel Frame Design ← Start Design/Check.
  4. Display ← Show Tables (Ctrl+T)، و تیک این‌ها:
    Analysis Results → Joint Output → Reactions
    Analysis Results → Joint Output → Displacements
    Design Data → Steel Design → Summary Data
    با دکمه Select Load Cases همه حالت‌ها و ترکیب‌ها را انتخاب کنید.
  5. در پنجره جدول‌ها: File ← Export All Tables ← To Excel و ذخیره.
