مقایسه با SAP2000

اثبات مستقل: مدل SAP خود دفتر با حل‌کننده برنامه حل می‌شود و هر عدد کنار خروجی خود SAP قرار می‌گیرد

ورودی

همان مدلی که در SAP طراحی کرده‌اید؛ یا فایل «مدل SAP سازه» که این برنامه ساخته است. در SAP: File ← Export ← SAP2000 .s2k Text File.
بدون این فایل، نتایج برنامه به قالب جدول‌های SAP (Excel) داده می‌شود تا دستی مقایسه کنید.

گرفتن خروجی از SAP

  1. مدل را در SAP باز کنید؛ واحد پایین صفحه Kgf, m, C باشد.
  2. تحلیل: Analyze ← Run Analysis (F5).
  3. طراحی: Design ← Steel Frame Design ← Start Design/Check.
  4. Display ← Show Tables (Ctrl+T) و انتخاب: Analysis Results ← Joint Output ← Reactions و Displacements، و Design Data ← Steel Design ← Summary Data؛ در Select Load Cases همه حالت‌ها و ترکیب‌ها.
  5. در پنجره جدول‌ها: File ← Export All Tables ← To Excel و ذخیره فایل.
  6. مدل و فایل Excel را این‌جا بدهید.
