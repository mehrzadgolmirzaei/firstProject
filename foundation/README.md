# محاسبه و ترسیم فونداسیون پایه تجهیزات پست

## نصب

```bash
python -m pip install ezdxf
```

## اجرا

```bash
python run.py LA                       # با تنظیمات project.json
python run.py LA --edition 4           # بازتولید دفترچه قدیمی
python run.py DSE
python run.py --save-project project.json   # ساخت فایل تنظیمات پیش‌فرض
```

تجهیزات: `LA CB CT CVT PI DSE DS DSROW`

خروجی در `out/`: گزارش markdown با تمام مراحل، و نقشه DXF.

## هیچ عددی در کد ثابت نیست

همه ورودی‌ها در `project.json` هستند و مهندس ویرایششان می‌کند:

| بخش | شامل |
|---|---|
| `materials` | fc ، fy ، پوشش بتن ، ضخامت مگر ، وزن مخصوص |
| `soil` | تنش مجاز پایه ، ضریب بار موقت ، اصطکاک |
| `seismic` | ویرایش ۴ یا ۵ ، SS ، S1 ، نوع زمین ، Ie ، Ru ، روش |
| `wind` | سرعت باد نرمال و شدید |
| `rebar` | قطر و فاصله آرماتور پی ، ستون ، خاموت ، خرک |
| `foundation` | ارتفاع و ضلع ستون ، ضخامت پی ، بازه جست‌وجو |
| `title_block` | تمام فیلدهای جدول عنوان کادر |
| `drawing` | مقیاس شیت و دیتیل ، مسیر کادر و تمپلیت |

**یادداشت‌های نقشه** در `notes.txt` هستند. هر خط یک بند. متغیرهای `{fc}`
و `{cover}` و `{q_all}` و `{seismic}` خودکار از همین تنظیمات پر می‌شوند.

**چیدمان شیت** در `layout.py` است — تنها بخشی که عمداً ثابت مانده، چون
استاندارد ترسیم دفتر شماست. مختصاتش از نقشه واقعی `06-4LA_C` برداشت شده.

## فایل‌های لازم کنار کد

| فایل | کار |
|---|---|
| `frame_blank.dxf` | کادر A3 خالی شرکت |
| `frame_reference.dxf` | کادر اصلی — مرجع مختصات فیلدهای جدول عنوان |
| `template.dxf` | مرجع لایه‌ها و سبک متن و سبک اندازه |
| `project.json` | تنظیمات پروژه |
| `notes.txt` | یادداشت‌های نقشه |

## چیدمان نقشه

شش ناحیه، مطابق نقشه واقعی شما:

PLAN · SECTION A-A · SECTION B-B (مقطع ستون) · DET."1" ANCHOR BOLT
BAR BENDING SCHEDULE · NOTE · کادر و جدول عنوان

کادر به صورت **بلاک** درج می‌شود نه XREF، پس فایل خروجی خودکفاست.
فیلدهای جدول عنوان از `title_block` پر می‌شوند: عنوان نقشه، شماره، مقیاس،
شماره صفحه، تهیه‌کننده، کنترل‌کننده، تأییدکننده و ردیف بازنگری.

## اعتبارسنجی

با ویرایش ۴، هر هشت تجهیز دقیقاً ابعاد دفترچه کامی‌آباد را می‌دهند، و متره
با نقشه `06-4LA_C` می‌خواند: بتن ۲٫۲۴ متر مکعب و مگر ۰٫۴۸۴ متر مکعب.
آرماتور پی هم همان `10Ф14@200` درمی‌آید.

## چه چیزی هنوز نیست

- زمان تناوب T — انتخاب صلب یا استاتیکی هنوز دستی است
- ترکیب ۱۰۰/۳۰ دو راستای زلزله
- طراحی میل مهار و صفحه کف
- پی مستطیلی و بهینه‌سازی ارتفاع ستون و ضخامت پی
- گِیج میل مهار فقط برای LA از نقشه واقعی است (۴۵۰ mm)؛ بقیه پیش‌فرض دارند

## اگر نقشه در اتوکد باز نشد

کلید F2 را بزنید و متن پیام را ببینید. تجربه قبلی: نام خالی در جدول
DIMSTYLE باعث می‌شد اتوکد کل فایل را دور بیندازد. الان فیلتر شده، ولی اگر
پیام دیگری دیدید همان متن را بفرستید.

برای عیب‌یابی: `python run.py LA --simple` نقشه را بدون موجودیت DIMENSION
می‌سازد.
